
# 🏠 전세역전 - 전세사기 방지 플랫폼

> **"전세 문제, 이제는 역전의 기회로!"**  
> 안전한 부동산 계약을 돕는 **전세사기 방지 서비스**, 전세역전입니다.

<br/>

## 📌 프로젝트 소개

**전세역전**은 부동산 계약에 익숙하지 않은 2030세대를 위해,  
전세사기 리포트 자동 생성, 계약서 자동 추천, 공인중개사 예약 기능까지  
**안전한 전세 계약을 위한 원스톱 솔루션**을 제공합니다.

- 전세사기 위험 리포트 자동 생성 (크롤링 + OpenAI 활용)
- 자동 계약서 생성 및 특약 문구 추천
- 신뢰할 수 있는 공인중개사 정보 및 예약 기능 제공
- 저장/조회 가능한 마이페이지 제공

<br/>

## 🖥 주요 기능

| 기능 | 설명 |
|------|------|
| 📋 전세사기 리포트 | 등기부등본 데이터를 기반으로 안전도 점수 및 리스크 요인 제공 |
| 📝 계약서 생성 | 리포트를 기반으로 맞춤형 계약서 자동 생성 (PDF 다운로드) |
| 📍 지도 기반 탐색 | 안전도 점수 기반 매물 지도 표시 및 필터 기능 |
| 👤 공인중개사 예약 | 사용자 위치 기반 인근 중개사 조회 및 예약 가능 |
| 💼 마이페이지 | 저장한 리포트, 계약서 열람 및 관리 가능 |

<br/>

## 🛠 기술 스택

| 분야 | 기술 |
|------|------|
| 프론트엔드 | Vue.js, Kakao Maps API |
| 백엔드 | Spring ,Mysql, MyBatis, REST API |
| AI 분석 | OpenAI GPT 기반 프롬프트 엔지니어링 |
| 데이터 수집 | Python, Selenium, BeautifulSoup, 공공데이터 API |
| 인프라 | AWS EC2, S3, MySQL, Docker, Redis |

<br/>

## 🧠 주요 기술적 시도

- 📄 PDF 문서에서 텍스트 추출 및 정제 (Apache Box, 패턴 기반 분석)
- 🧠 AI 프롬프트 엔지니어링을 통한 계약 리스크 요약 자동화
- 🔄 계약서 자동 생성 템플릿 시스템 (S3 Presigned URL + EC2 저장)
- 🗺 지도 좌표 ↔ 법정동 코드 변환 및 캐싱 처리 
- 📊 전세 리스크 분석 알고리즘 (매매가 대비 보증금, 낙찰가 대비 선순위 등 11가지 항목 분석)
